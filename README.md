# 42 C Exam Practice

> Created by **[LeoDanoGG](https://github.com/LeoDanoGG)** as part of my personal programming practice and learning journey.

A personal repository dedicated to practising and improving my `C` programming skills through exercises inspired by the 42 Network exam system.

The goal of this repository is to strengthen programming fundamentals, develop problem-solving skills and gain confidence when working with `C`.

## Disclaimer

This is an independent educational project created for personal practice and learning purposes.

It is not affiliated with, endorsed by, or an official project of 42 Network or [42exam.net](https://42exam.net).

Exercise names and concepts are used for identification and educational reference. All solutions and original explanations in this repository are independently written.

## Repository Structure

Exercises are organized by difficulty level, following the structure used in the 42 C exams.

| Level | Description |
|:---:|---|
| [`Level 1`](level1/README.md) | Basic programming concepts and operations. |
| [`Level 2`](level2/README.md) | String manipulation, arrays and basic algorithms. |
| [`Level 3`](level3/README.md) | More advanced problem-solving and data manipulation. |
| [`Level 4`](level4/README.md) | Advanced `C` programming exercises. |

*More levels and exercises may be added over time.*

## Purpose

- Practise C programming and improve code quality.
- Develop logical thinking and problem-solving skills.
- Reinforce fundamental concepts through practical exercises.
- Track personal progress across different difficulty levels.
