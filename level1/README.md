# Level 1

| Exercise | Description |
|:---:|:---|
| [`first_word`](first_word.c) | Takes the first word of the `string` from the first argument to the console. |
| [`pingpong`](pingpong.c) | Prints the numbers from 1 to 100, and depending on whether each number is a multiple of 3, 5, or both, Prints `ping`, `pong`, or `pingpong`. |
| [`my_putstr`](my_putstr.c) | Prints a `string` obtained from argument of the function call. |
| [`my_strcpy`](my_strcpy.c) | Copies a `string` into another (blind copy). |
| [`my_strlen`](my_strlen.c) | Reads the `string` passed as argument and returns its length. |
| [`my_swap`](my_swap.c) | Swaps the value of two variables passed by its memory addres (&). |
| [`repeat_alpha`](repeat_alpha.c) | Repeats a letter the same amount of times as its position in the alphabet. |
| [`rev_print`](rev_print.c) | Prints the `string` passed as the first argument in reverse.  |
| [`caesar`](caesar.c) | Moves the letters of the `string` passed as the first argument to the console one letter forward (a -> b, z -> a). |
| [`caesar_cipher`](caesar_cipher.c) | Moves the letters of the `string` passed as the first argument to the console  based on the second argument to the console. |
| [`ctrl_h`](ctrl_h.c) | Searches on the `string` passed as the first argument passed to the console if it has the `char` passed as the second argument; then if it has the `char` is changed by the `char` passed as the third argument. |
| [`swap_cap`](swap_cap.c) | Swaps the lower and uppercase letters in the `string` passed as the first argument to the console (a -> A, A -> a). |
